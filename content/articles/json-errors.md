## 适用条件

适用于 JSON API 响应、配置或结构化数据。目标格式本身是 JSONC 时，请按项目支持的规则处理注释。

## 操作步骤

### 1. 先获得原始文本

将待检查的原文粘贴到 JSON 格式化工具，执行「校验」并查看行列。错误也可能来自上一个字段末尾，从该位置向前检查一行。

### 2. 对照 JSON 语法

对象的属性名和文本值使用双引号。最后一项后面不能有逗号，文件里也不能用注释。字符串中的反斜杠和双引号需要转义。

```text
{"project":"Shanhai Nexus","enabled":true}
```

### 3. 检查内容是否真的是 JSON

若错误出现在第一个字符，检查接口状态码和 Content-Type。代理、登录跳转或网关可能返回 HTML。把修复后的文本再次校验。

## 常见问题

### 能否把大整数交给格式化工具？

站内工具保留数字原文。其他程序若把大整数读成 JavaScript Number，可能丢失精度。
