## 适用条件

适用于 URL 中单个查询参数的键和值。已有完整 URL 时，可用 URL 与 URLSearchParams 读写参数。

## 操作步骤

### 1. 提取待编码的值

只复制参数值，保留参数名和外层 URL 的问号、等号与 &。例如要在 q 中传递“山海 & 海图”，对这段文字编码。

### 2. 编码并加入地址

使用站内 URL 编解码工具，选择「URL 组件」。编码后把结果放到 q= 后，& 会以百分号编码保留在值里。

### 3. 检查解码方式

普通 URL 组件中的 + 会保留。表单格式用 + 代表空格，并以 %2B 表示加号。解码时选择和发送方相同的格式。

## 常见问题

### 为什么 % 变成了 %25？

常见原因是对已经编码的值又执行一次编码。通常从原始值开始，由 URLSearchParams 或编码工具处理一次。
