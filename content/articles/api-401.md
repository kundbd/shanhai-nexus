## 适用条件

适用于拿到 401 响应且有权查看调用配置的场合。请使用脱敏日志。

## 操作步骤

### 1. 检查错误类型与请求地址

记录 HTTP 状态和响应中的错误类型。确认 Base URL 指向密钥所属的供应商或网关。

### 2. 核对凭据是否随请求发送

查看 SDK 的认证配置和服务实际读取的环境变量。若提供方要求 Bearer 认证，确认格式完整。检查时只记录密钥是否存在。

```text
Authorization: Bearer <YOUR_API_KEY>
```

### 3. 核对密钥状态和项目

在供应商控制台核对密钥是否被撤销，检查组织、项目与允许来源。更新密钥后让相应进程重新加载，再用最小请求验证。

## 常见问题

### 重启进程是否总能解决？

只会帮助加载变更后的配置。若供应商拒绝密钥或来源，仍需处理相应配置。
