## 适用条件

适用于 Windows 10 或 Windows 11 连接家用 Wi-Fi 但打不开网页。校内或公司网络应遵循管理员的配置。

## 操作步骤

### 1. 先找出受影响的范围

用手机连到同一 Wi-Fi，临时关闭蜂窝数据后测试。如果所有设备都失败，检查路由器的互联网状态和运营商故障通知。可以在确认无人依赖当前连接时重启路由器。

### 2. 检查电脑的 Wi-Fi 与地址

若只有电脑失败，确认连的是正确网络，关开 Wi-Fi 后重连。在 Windows 11 可通过「获取帮助」运行网络和 Internet 疑难解答。若 ipconfig 显示 169.254 开头的 IPv4，先排查 DHCP 地址分配。

```text
ipconfig /all
```

### 3. 区分网页故障与解析故障

测试两个平时可访问的站点。用 nslookup 查询失败站点；若地址可解析但页面仍失败，核对登录门户、VPN、代理、浏览器和时钟。公司配置请让管理员检查。

```text
nslookup example.com
```

## 常见问题

### 清理 DNS 缓存会修好所有断网吗？

它只会清理本机 DNS 缓存。路由器掉线、DHCP 失败或站点故障需要分别处理。
