## 适用条件

适用于服务器收到请求但明确拒绝访问的场合。以响应层和提供方政策为准。

## 操作步骤

### 1. 确认响应由哪一层返回

核对响应正文和请求 ID。若返回代理页面或网关提示，先检查该层自己的访问策略。

### 2. 检查项目和资源权限

在供应商控制台核对请求对应的项目、模型、端点与 API 密钥权限。由管理员按实际用途授予所需权限。

### 3. 核对供应商的可用范围

若响应明确指向区域或组织限制，对照提供方的可用范围与组织政策。保留脱敏后的请求 ID，便于管理员或供应商查询。

## 常见问题

### 换新密钥能消除 403 吗？

权限与区域策略与实际项目、账户和资源相关。请先确认拒绝原因。
