# 地区内容分流验收记录

2026 年 11 月 19 日在独立工作目录验证。使用 Node.js 24、Next.js 16.4.6、Chrome 和 DB-IP Country Lite 2026 年 11 月版。正式站的公网地区验收安排在获批部署后。

| 检查项 | 结果 |
| --- | --- |
| 类型、Lint 和生产构建 | 全部通过。地区相关页面和站点地图按请求渲染 |
| 单元测试 | 111 项通过，包括未知地区、国家库缺失或损坏、机场与 VPN 归档保护 |
| 生产构建集成测试 | 10 项通过。回环代理模拟中国大陆、香港、美国和未知对端。同一 URL 的直链、搜索、关联内容、广告和缓存符合各地区规则 |
| 地区浏览器验证 | 中国大陆手机尺寸和香港桌面尺寸验证了页脚、广告及教程。同一教程在中国大陆返回 404，在香港正常打开。香港轮播可以切换到设为境外可见的测试卡片 |
| 既有浏览器用例 | 桌面 15 项通过，手机 13 项通过。原有真实导入数据或仅桌面用例按各自条件跳过 26 项。两个项目分别使用新建测试库 |
| 后台 | 现有管理员登录可保存地区规则并生成审核记录。未登录或来源校验失败的请求无法写入 |
| 数据迁移 | 在离线副本升级至 042 后保留迁移前备份。执行 043 并重复启动，原有 61 张业务表的 112,727 条记录逐表摘要一致，其中有 1,554 家服务商和 14,937 条报价。完整性和外键检查通过 |
| 地区查询开销 | 本机 600 次预热后的国家识别与 SQLite 规则读取中位数约 0.05 毫秒，P95 约 0.11 毫秒 |

集成测试通过受控代理追加测试对端地址。客户端提供的地区参数和国家头不改变规则。相同地址的 HTML 和 React Server Components 响应经过中国大陆和香港交叉检查，预取响应也没有包含受限正文。站点地图使用同一份全地区可见清单。设为受限的测试邀请码未进入浏览器静态脚本。

既有首页回归用例改为检查目前的搜索框，并等待工具中心实际渲染后再打开知识中心。评价测试会修改测试库的屏蔽词，因此两个浏览器项目独立执行。

离线迁移脚本校验并保留 `output/geo-tests/upgrade-*/pre-043.sqlite`。构建产物、测试数据和国家库位于 Git 忽略目录。正式发布前按部署说明另做线上数据库备份。

## 顶部标识与境外开放

113 项单元测试和 11 项地区集成测试通过。Chrome 桌面和手机尺寸检查了顶部文字、旗帜和版面宽度。中国台湾和中国大陆使用同一中国国旗图样。新加坡、德国和美国显示各自的旗帜与名称。澳大利亚显示「其他区域」，可以访问设为境外开放的档案。

旧库副本通过 044 迁移与重复启动检查。迁移恢复了 238 条符合条件的档案，写入 242 条地区规则，保留其余报价和原有数据。中国大陆与未知出口的受限档案直链仍返回 404。正式数据库的只读检查也选出了 238 条档案。
